# Ashwini Mali — Developer & AI Portfolio Website

A sleek, modern Developer & Terminal-aesthetic portfolio website crafted specifically for Software Engineering, AI & Machine Learning internships and interviews.

---

## 🌟 Key Features
- **Developer / Terminal Aesthetic:** Dark mode color scheme (`#0a0d14`), subtle glowing accents, monospace code headers, and responsive glassmorphism cards.
- **Interactive Terminal Engine:** Fully functional CLI in the hero section supporting commands like `help`, `skills`, `projects`, `about`, `education`, `contact`, and `clear`, plus quick-tap chips for non-technical visitors.
- **Dynamic Typing Animation:** Engaging live rotating roles (`AI & Data Science Engineer`, `Computer Vision Builder`, `Python & C Developer`, `Women's Safety Tech Innovator`).
- **Interview-Optimized Project Cards:** Dedicated **"Interview Talking Points"** for each project highlighting technical architecture, problem-solving impact, and key libraries (`OpenCV`, `MediaPipe`, `Twilio API`, `pyttsx3`, `C/Python Data Structures`).
- **One-Click Interactions:** Instant "Copy Email" button with copied notification, direct GitHub links, and smooth navigation.
- **Zero-Dependency Architecture:** Pure semantic HTML5, modern CSS3, and vanilla JavaScript. Runs out-of-the-box without Node.js or any build steps required.

## 🌐 How to Deploy for Free on GitHub Pages (2 Minutes)
To make your portfolio accessible worldwide to interviewers and recruiters:

1. Create a new repository on your GitHub account (`https://github.com/ashwinimali4753-cell`) named `portfolio` (or `ashwinimali4753-cell.github.io`).
2. Upload the 3 files (`index.html`, `style.css`, `script.js`) into that repository.
3. In the repository settings:
   - Go to **Settings** > **Pages** (under Code and automation).
   - Under **Build and deployment** > **Branch**, select `main` (or `master`) and folder `/ (root)`.
   - Click **Save**.
4. Within 60 seconds, your portfolio will be live at:
   ```
   https://ashwinimali4753-cell.github.io/portfolio/
   ```
5. You can now place this link directly on your **Resume**, **LinkedIn**, and job applications!

## ✏️ How to Customize Links Anytime
- **Email:** Search for `ashwinimali.work@gmail.com` in `index.html` and `script.js` to change it to your desired email.
- **LinkedIn:** Search for `https://linkedin.com` in `index.html` and replace it with your personal LinkedIn profile URL.
- **Resume File:** Place your `resume.pdf` in the same directory and link to it via `<a href="resume.pdf">Download Resume</a>`.
